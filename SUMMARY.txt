🎯 CÁC TÍNH NĂNG CHÍNH
================================================================================

1. SHIFT REGISTER CONTROL (GPIO)
   - writeShift(mask) → Ghi 16-bit vào 2×74HC595
   - setLed(index, on) → Bật/tắt 1 LED
   - clearAll() → Tắt tất cả

2. Wi-Fi CONNECTIVITY
   - connectWifi() → Kết nối mạng (Wokwi-GUEST hoặc tùy chỉnh)

3. MQTT COMMUNICATION
   - connectMqtt() → Kết nối broker + subscribe topic
   - handleMqtt() → Xử lý lệnh JSON từ app/cloud
   - Payload JSON với action: on/off/set/setMany/clear

4. WOKWI SIMULATION
   - Diagram đầy đủ: ESP32 + 2×74HC595 + 16 LED (đa sắc)
   - Chạy firmware ngay trong browser, không cần kit thật

================================================================================
📝 PAYLOAD JSON EXAMPLES
================================================================================

Bật 1 LED:
  {"action":"on","ledIndex":0}

Tắt 1 LED:
  {"action":"off","ledIndex":5}

Tắt tất cả:
  {"action":"clear"}

Bitmask (ghi trực tiếp):
  {"action":"set","mask":255}        → LED 0-7 sáng
  {"action":"set","mask":65535}      → Tất cả 16 LED

Danh sách kênh:
  {"action":"setMany","channels":[0,2,4,6],"state":true}
  {"action":"setMany","channels":[1,5,10],"state":false}

================================================================================
🛠️ TROUBLESHOOT
================================================================================

Problem: WiFi failed
  → Check SSID/password in config.h
  → Ping broker.emqx.io

Problem: MQTT connection failed
  → Check MQTT_HOST is reachable
  → Verify Wi-Fi is connected first

Problem: LED không sáng (Wokwi)
  → Check wokwi.json connections
  → Verify GPIO pins match

Problem: JSON parse error
  → Check payload syntax (use jsonlint.com)
  → Verify quotes are not escaped

Problem: No USB detected
  → Install ESP32 CH340 driver
  → Check USB cable (not charging-only)
